# Ajedrez local v0.2.0

Esta versión permite guardar una partida local y recuperarla en otra ejecución,
con su historial completo y los datos necesarios para continuar jugando.

## Novedades

- **Guardar partida** y **Abrir partida** en la ventana principal.
- Archivos JSON con posición inicial, jugadas, promociones, turno y resultado.
- Recuperación de los derechos de enroque, captura al paso, contador de medios
  movimientos y repeticiones de posiciones.
- Opción de guardar, descartar o cancelar antes de cerrar o sustituir una partida
  que tenga cambios pendientes.
- Conservación del archivo anterior si falla la escritura. Un archivo no válido
  se rechaza sin reemplazar la partida abierta.
- Documentación del formato y pruebas de recuperación entre procesos de Python.

Las partidas terminadas conservan su resultado y siguen disponibles para
consultar el historial y explorar variantes.

## Instalación o actualización en Windows

Necesitas Python 3.13 o posterior con Tkinter. Descarga el archivo
`ajedrez_local-0.2.0-py3-none-any.whl` adjunto. Para una instalación nueva, abre
PowerShell en la carpeta de descarga:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --no-deps .\ajedrez_local-0.2.0-py3-none-any.whl
.\.venv\Scripts\ajedrez.exe
```

Si ya tienes la versión 0.1.0, cierra la aplicación e instala este paquete con el
Python del mismo entorno virtual. No hace falta recrear el entorno.
El paquete incluye los recursos gráficos y no requiere dependencias externas de
ejecución. No es un ejecutable autónomo.

`SHA256SUMS.txt` contiene la suma del paquete. Puedes compararla con:

```powershell
Get-FileHash .\ajedrez_local-0.2.0-py3-none-any.whl -Algorithm SHA256
```

## Qué se guarda

Se guarda siempre la **partida original**, aunque se esté consultando el historial
o trabajando en un análisis. Las variantes, anotaciones, preferencias visuales y
propuestas de tablas pendientes siguen siendo temporales. Si hay una promoción
pendiente, hay que elegir la pieza antes de guardar.

El formato JSON es propio de la aplicación; todavía no se importan ni exportan
archivos PGN o FEN. No se necesita una base de datos para usar este guardado.

## Verificación y alcance

La publicación requiere superar **432 pruebas** del proyecto en Windows con
Python 3.13 y **tres comprobaciones del paquete instalado** en un entorno limpio.
El paquete adjunto es el mismo que supera ese proceso.

Se mantienen las limitaciones documentadas: no hay oponente de IA, juego remoto,
cuentas de usuario, biblioteca de partidas en base de datos, menú general de
preferencias ni animación del desplazamiento. La detección de posiciones muertas
cubre los casos documentados de material insuficiente y bloqueos permanentes,
pero no todas las posiciones posibles. Otros sistemas operativos no están
verificados.
