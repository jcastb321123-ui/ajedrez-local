# Ajedrez local v0.4.0

Esta versión incorpora el diálogo **Preferencias** para elegir el aspecto del
tablero y el resaltado del jaque, y recuperar esa configuración al volver a abrir
la aplicación. Las preferencias se guardan por separado de las partidas.

## Novedades

- Doce temas del catálogo, con distintas paletas y acabados.
- Tres modos de jaque: rey permanente, parpadeo tras rechazar un movimiento que
  deja al rey en jaque, o rey y piezas atacantes permanentes.
- Aplicar, cancelar y restablecer la elección predeterminada desde el diálogo.
- Cambio de tema conservando la partida, la posición mostrada, la selección,
  las anotaciones y las flechas seleccionadas.
- Actualización del panel de análisis, su editor y el selector de promoción
  pendiente, conservando sus estados.
- Recuperación de las preferencias al iniciar. Si el archivo no puede usarse,
  la aplicación avisa y utiliza valores predeterminados sin sobrescribirlo.
- Escritura mediante un archivo temporal: si falla, se conserva la configuración
  anterior y el diálogo permite reintentar.

Cancelar, Escape y cerrar el diálogo no guardan cambios. Restablecer los valores
predeterminados requiere pulsar **Aplicar** para confirmarlos. El intervalo y el
número de parpadeos se conservan, aunque el diálogo no permite editarlos todavía.

## Instalación y actualización

Necesitas Python 3.13 o posterior con Tkinter. Descarga
`ajedrez_local-0.4.0-py3-none-any.whl` y, desde su carpeta, ejecuta:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --no-deps .\ajedrez_local-0.4.0-py3-none-any.whl
.\.venv\Scripts\ajedrez.exe
```

Si ya tienes un entorno para la aplicación, cierra sus ventanas e instala el
nuevo paquete con el Python de ese entorno, sin recrearlo. Se mantienen la
biblioteca SQLite de v0.3.0 y los archivos de partida JSON de v0.2.0 y v0.3.0;
no requieren migración. El paquete incluye las imágenes y no necesita
dependencias externas de ejecución. No es un ejecutable autónomo.

En Windows, los datos se conservan fuera de la instalación:

- `%LOCALAPPDATA%\ajedrez-local\preferencias.json`: configuración gráfica.
- `%LOCALAPPDATA%\ajedrez-local\biblioteca.sqlite3`: partidas guardadas.

La primera apertura utiliza las preferencias predeterminadas si el archivo no
existe. Se crea al pulsar **Aplicar**. Cambiar preferencias no guarda una partida
ni modifica sus cambios pendientes. Las variantes y anotaciones siguen siendo
temporales.

La entrega incluye `SHA256SUMS.txt`. Comprueba la descarga con:

```powershell
Get-FileHash .\ajedrez_local-0.4.0-py3-none-any.whl -Algorithm SHA256
```

## Verificación y alcance

La publicación exige superar 531 pruebas del proyecto y cinco comprobaciones
del paquete instalado en Windows con Python 3.13. Incluyen widgets reales,
biblioteca SQLite y recuperación de preferencias entre dos arranques. Se publica
el mismo paquete que supera estas comprobaciones.

Esta entrega ofrece juego local y análisis. Siguen pendientes la IA, las partidas
remotas, las cuentas de usuario y la animación. La detección de posiciones muertas
conserva las limitaciones documentadas; otros sistemas operativos no se han
verificado.
