# Ajedrez local v0.1.0

Primera entrega pública: una aplicación de escritorio en Python y Tkinter para
jugar entre dos personas en el mismo equipo y explorar variantes sin modificar
la partida original.

## Incluye

- Validación de movimientos, capturas, enroque, captura al paso y promoción.
- Abandono, propuestas de tablas, reclamaciones por triple repetición y cincuenta
  movimientos, y tablas automáticas por cinco repeticiones y setenta y cinco
  movimientos. Las reclamaciones admiten movimientos anunciados.
- Navegación por el historial, flechas y resaltados estratégicos.
- Análisis hipotético en el tablero principal o en un panel independiente, con
  editor de posiciones.
- Recursos gráficos incluidos, documentación de arquitectura y licencia MIT.

## Instalación en Windows

Necesitas Python 3.13 o posterior con Tkinter. Descarga el archivo
`ajedrez_local-0.1.0-py3-none-any.whl` adjunto y abre PowerShell en esa carpeta:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --no-deps .\ajedrez_local-0.1.0-py3-none-any.whl
.\.venv\Scripts\ajedrez.exe
```

El paquete contiene los recursos gráficos y no necesita dependencias externas
de ejecución. No es un ejecutable autónomo: utiliza el Python del entorno virtual.
`SHA256SUMS.txt` contiene la suma del paquete; puedes compararla con la salida de:

```powershell
Get-FileHash .\ajedrez_local-0.1.0-py3-none-any.whl -Algorithm SHA256
```

## Verificación

La publicación requiere superar 407 pruebas del proyecto en Windows con Python
3.13, construir el paquete, instalarlo en un entorno limpio y pasar las dos
comprobaciones de la aplicación instalada. El paquete adjunto es el que supera
ese proceso. La etiqueta identifica el commit utilizado.

## Alcance y limitaciones

Esta entrega permite partidas locales entre dos personas. Todavía no incluye
oponente de IA, juego remoto, cuentas de usuario, guardado de partidas entre
ejecuciones, menú general de preferencias ni animación del desplazamiento.

La detección de posiciones muertas reconoce los casos documentados de material
insuficiente y bloqueos permanentes; no cubre todas las posiciones muertas
posibles. El funcionamiento en otros sistemas operativos no está verificado.

Consulta el [README](https://github.com/jcastb321123-ui/ajedrez-local/blob/v0.1.0/readme.md)
para conocer los controles, las reglas implementadas y las limitaciones detalladas.
