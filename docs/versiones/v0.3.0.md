# Ajedrez local v0.3.0

Esta versión incorpora una biblioteca de partidas SQLite a la aplicación local.
Permite conservar varias partidas, encontrarlas por título y fecha, abrirlas,
continuar jugando y guardar sus avances en el mismo registro.

## Novedades

- **Biblioteca** muestra las partidas por último guardado, con título y fechas.
- **Guardar partida actual** crea un registro o actualiza el asociado a la partida.
- **Guardar copia** conserva una segunda entrada independiente.
- **Abrir** recupera el historial, el turno, el resultado y los metadatos del juego.
- **Eliminar** pide confirmación y conserva la partida que esté en pantalla.
- **Abrir archivo** y **Exportar archivo** permiten intercambiar partidas JSON.
- El guardado habitual respeta el destino de la partida abierta: archivo o biblioteca.
- Las escrituras son transaccionales; un fallo no deja un guardado o borrado parcial.

La biblioteca guarda el modelo `Partida`, independientemente de la modalidad.
Las capacidades de `Sesion` determinan si la interfaz permite guardar. La
aplicación de esta versión continúa ofreciendo juego local y análisis; no incorpora
IA, comunicación remota ni cuentas de usuario.

## Instalación y datos

Necesitas Python 3.13 o posterior con Tkinter. Descarga
`ajedrez_local-0.3.0-py3-none-any.whl` y, desde su carpeta, instala en tu entorno:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --no-deps .\ajedrez_local-0.3.0-py3-none-any.whl
.\.venv\Scripts\ajedrez.exe
```

Si ya utilizas un entorno para la aplicación, cierra sus ventanas e instala el
nuevo paquete con el Python de ese entorno, sin recrearlo. Los archivos JSON de
v0.2.0 siguen siendo compatibles: ábrelos y usa **Biblioteca → Guardar partida actual**.

En Windows, la biblioteca se crea en
`%LOCALAPPDATA%\ajedrez-local\biblioteca.sqlite3`. Está fuera de la instalación y
se conserva al actualizar el paquete. Puedes respaldar el archivo con la aplicación
cerrada o exportar partidas individuales. El paquete incluye las imágenes y no
requiere dependencias externas de ejecución; no es un ejecutable autónomo.

`SHA256SUMS.txt` contiene la suma del paquete publicado. Puedes comprobarla con:

```powershell
Get-FileHash .\ajedrez_local-0.3.0-py3-none-any.whl -Algorithm SHA256
```

## Alcance

Se guarda la partida original, incluso al consultar el historial o una variante.
Las anotaciones, variantes, preferencias y propuestas de tablas pendientes siguen
siendo temporales. Una promoción pendiente debe resolverse antes de guardar.
Exportar no marca como guardados los cambios pendientes en el destino habitual.

Siguen pendientes las modalidades contra IA y remota, las cuentas, el menú de
preferencias y la animación. La detección de posiciones muertas conserva las
limitaciones documentadas. Otros sistemas operativos no están verificados.

La publicación exige superar 485 pruebas del proyecto y cuatro comprobaciones del
paquete instalado en Windows, incluyendo el recorrido de biblioteca con SQLite
y widgets reales. Se publica el mismo paquete que supera esa comprobación.
Consulta el [README](https://github.com/jcastb321123-ui/ajedrez-local/blob/v0.3.0/readme.md)
y el [diseño de persistencia](https://github.com/jcastb321123-ui/ajedrez-local/blob/v0.3.0/docs/persistencia.md).
